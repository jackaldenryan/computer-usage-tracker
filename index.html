Settings

Manual = your entered minutes. Auto = display-off gaps measured from the power log. Charts, totals and averages all follow this toggle.

Hours before this time count toward the previous day. Default 4 AM — so working until 2 AM is still yesterday.

—

CSV columns: date, start, stop, subtract_manual_minutes, subtract_auto_minutes, hours_worked. Imports cleanly into Google Sheets (File → Import → Upload the file above).

Tracking source: pmset -g log → first “Display is turned on” = start, last “Display is turned off” = stop, display-off gaps = auto subtract. Backfills on every launch, so quitting the app loses nothing.

Backfill from CSV

Upload a CSV to add older days. Required columns: date (YYYY-MM-DD) + hours_worked (final hours, gaps already accounted for). Optional: start, stop, subtract_manual_minutes, subtract_auto_minutes. Missing subtracts are stored as n/a and uploaded hours are trusted as-is in both modes. Existing dates are merged (hours replaced; other fields only when provided).
